Website Auditor

Enter a website, press Run scan, and follow every stage live. The audit runs in your GitHub repository's Actions — this page only starts it and shows progress.

1. Connect to GitHub

How do I get a token?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → pick this audit repository.
  3. Permissions → Repository: Actions: Read and write. Nothing else is needed.
  4. Paste it above. It is sent only to api.github.com and never stored in the repository.

Only people who already have access to the repository can create a working token, so this page gives nobody new access.

2. What should be scanned?

One per line. A sitemap.xml link is expanded into the pages it lists. Only public http(s) sites can be scanned. Leave empty to use the repository's saved SITE_URLS list.

Only scan sites you are allowed to test. The URLs you enter are visible to anyone with access to the repository's Actions runs.
